# Veille techno — 2026-10-15

## À retenir

1. **SAB-070 — UniFi Protect AI Key : 3 failles (14/10)** — Path traversal avec lecture de fichiers (CVE-2026-110457), path traversal avec création/troncature de fichiers (CVE-2026-110458, CVSS 3.7), contrôle d'accès permettant d'accéder aux ressources internes via l'appareil (CVE-2026-110454, CVSS 5.3). Correctif : firmware AI Key + restreindre l'accès réseau. Pas d'impact sur les contrôleurs Network, mais à traiter si un AI Key traîne dans un déploiement. 🎯 — **10/10** ✅
2. **UniFi Network Application 11.0.83 (RC)** — Première salve de la branche 11, exige UniFi OS 6.0+, upgrade pouvant prendre 20 min. À tester hors production avant tout déploiement client. 🎯 — **9.6/10** ✅
3. **VoqadoWiFi généralise le consentement explicite (oct. 2026)** — Case « conditions WiFi » requise + case marketing séparée non pré-cochée sur tous ses portails ; chaque choix est stocké avec le libellé exact affiché et l'horodatage ; sync Mailchimp limitée aux opt-ins. Le consentement traçable devient un argument produit du captive portal — directement transposable à notre offre. 🎯 — **9.3/10** ✅
4. **Inspection IA d'infrastructures électriques par smartphone** (HF paper 2610.17620) — Système d'inspection IA field-deployed, sans cloud. Transposable au contrôle qualité photo de nos installations (mâts, câblage, équipements) sur le terrain. 🎯 — **9.1/10** ✅
5. **Liquid AI LFM2.5-24B-A2B** — Modèle MoE 24B « built for fast on-device agents ». Piste crédible pour de l'IA locale embarquée (assistant terrain, hors-ligne). — **7.5/10** ✅
