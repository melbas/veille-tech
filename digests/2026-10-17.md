## À retenir

1. **Claude Agent SDK : exécution de commande arbitraire (critique)** — 8.6 ✅
   Le SDK Python passait l'option `resume` au CLI sans validation : un `resume` contrôlé par l'attaquant permet d'injecter `--mcp-config` et d'exécuter une commande au démarrage, en contournant les permissions. Corrigé en `claude-agent-sdk` **0.2.121**. Ne touche directement que les apps qui passent une entrée non fiable comme session ID — mais si un de nos outils s'appuie sur le SDK, mise à jour immédiate.
   https://github.com/advisories/GHSA-h4mw-j7qp-8mwm (16/10)

2. **Comment l'équipe Claude Code fait sa code review** — 7.9 ✅
   Blog de l'équipe : ce que l'IA révise, ce qu'on lui laisse, et où ça casse. Directement pertinent pour notre pratique solo (pas de relecteur humain) : à comparer avec notre usage Hermes/Claude Code.
   https://claude.dev/blog/solving-code-review-at-anthropic/ (16/10)

3. **iroh 1.0** — 7.4 ✅
   La lib Rust de tunnels P2P (QUIC, hole-punching, relais) atteint 1.0. Alternative crédible à un VPN WireGuard managé type Netmaker pour relier des sites clients sans IP publique — à garder en tête pour les déploiements WISP multi-sites.
   https://www.iroh.computer/blog/the-road-to-iroh-1-0 (16/10)

4. **context-mode : optimisation de fenêtre de contexte pour agents** — 6.6 ✅
   Sandboxing des sorties d'outils (−98 % annoncé, chiffre éditeur non vérifié), mémoire de session, routage MCP+hooks sur 17 plateformes. Intéressant pour nos sessions Hermes longues.
   https://github.com/mksglu/context-mode (17/10)
