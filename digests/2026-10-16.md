## À retenir

1. **TanStack Start : XSS réfléchi non authentifié, CVSS 9.3 (CVE-2026-102989)** — ✅ Confirmé. Une URL forgée vers une server function fait renvoyer du HTML contrôlé par l'attaquant depuis l'origine de l'app (vol de session, requêtes avec l'autorité du visiteur). Pertinent pour nos portails React/SSR. Score 8.0. https://github.com/advisories/GHSA-qx66-fv34-fjm8 (15/10)
2. **Claude Code écrit un pilote Linux complet par rétro-ingénierie hardware** — ✅ Confirmé, 🎯 Métier WISP. Un chipset de scanner devenu non supporté : pilote SANE reconstruit à partir des binaires avec Claude Code. Transposable : faire fonctionner du matériel non supporté (CPE, radio, périphériques) sur nos serveurs Linux. Score 8.9. https://blogs.gnome.org/uraeus/2026/10/15/aiandreverseengineerhardware/ (15/10)
3. **JevAgentHarness : benchmark des decision models qui partagent le contrôle avec un LLM** — ✅ Confirmé. Un harness d'agent délègue ses choix multiple-choice (quel tool appeler) à un decision model type Jev, bien plus rapide et moins cher qu'un appel LLM ; le paper mesure la perte de succès. C'est exactement l'architecture du plugin Jev de notre Hermes. Score 7.9. https://arxiv.org/abs/2610.21412 (15/10)
4. **Claude Code : contournement du pinning par hash de plugin (CVE-2026-86063, high)** — ✅ Confirmé. Le checkout de la SHA épinglée ne vérifiait pas le HEAD résultant : une branche nommée comme la SHA suffit à servir du code arbitraire à l'install. Concernant tous nos plugins/skills installés depuis des marketplaces. Score 7.2. https://github.com/advisories/GHSA-pq7j-f95f-qfcv (15/10)

## 🎯 IA appliquée à mon métier

- **Rétro-ingénierie hardware assistée Claude Code (pilote SANE)** — voir À retenir #2. Le point clé du billet : bloquer puis reprendre après échec, et raisonner au niveau bus/signaux plutôt qu'au niveau code. Cas d'usage direct : matériels exotiques sur nos serveurs de gestion. Score 8.9 ✅
- **« Un LLM est un analyste peu fiable mais un bon fabricant d'outils »** — paper Cambridge sur le décodage des protobuf iOS→Apple : les schémas reconstruits par frontier models (Claude Opus 4.8, GPT) contiennent massivement des erreurs *difficiles à détecter car internes cohérents* ; en revanche le LLM écrit des outils fiables quand leur sortie est validable. Règle à retenir pour toute analyse RE/forensique assistée IA : exiger un oracle de validation. Score 8.5 ✅ https://arxiv.org/abs/2610.21597 (15/10)
